# Product Analytics Dashboard

This project is developed as part of the Dyne Infotech machine test assignment.

The application provides product analytics and insights using uploaded CSV/Excel product data.

## Features

- Upload CSV/Excel files
- Display products in table format
- Search products by name
- Pagination support
- Product analytics charts
- Category-wise product analysis
- Discount distribution visualization
- Responsive dashboard UI

## Technologies Used

Frontend:

- React.js
- Material UI
- Recharts

Backend:

- Node.js
- Express.js

Database:

- PostgreSQL

## Project Structure

- frontend → React application
- backend → Node.js and Express API

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```

## Run Backend

```bash
cd backend
npm install
npm run dev
```

## Database

PostgreSQL is used for storing uploaded product data.

## Main Functionalities

- File upload and processing
- REST API integration
- Analytics dashboard
- Search and filtering
- Data visualization
